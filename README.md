# SpeicherPilot

**BESS planning & Germany grid briefing**

Next.js demo for Megapack-style sizing, live generation/load snapshots, indicative DE-market economics, site markers on a Germany map, and PDF proposals — aligned to a Tesla BESS sales-engineer workflow.

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000).
